# Changelog

All notable changes to this project are documented in this file.

## [1.2.0] - 2026-11-24

### Added

- Flashcards: a **Download CSV** button (BM: **Muat turun CSV**) saves the current deck as a CSV file that Anki can import, with one row per card (front, back, topic tag) and the header lines from the Anki text import manual. Shown during review and on the "Deck reviewed" screen. Requested in [#4](https://github.com/aimanmalib/learnpath/issues/4).

Inspired by [SYuan03/Skill-Anything](https://github.com/SYuan03/Skill-Anything), which exports flashcards to an Anki-ready file.
